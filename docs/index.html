Workflows + Utilities Runtime

Operate Xyte fleets with deterministic workflows and utilities.

xyte-cli gives coding agents and operators one deterministic runtime for utility pipelines, deterministic flow runs, guarded endpoint writes, interactive TUI workflows, and schema-validated JSON outputs.

xyte-cli quickstart 
# install
npm install -g @xyteai/cli@latest
xyte-cli --help

# setup
XYTE_CLI_KEY="<your-key>" \
xyte-cli setup run --non-interactive --tenant acme --connectivity auto
xyte-cli status --tenant acme --mode fast --format json

# headless snapshot for agents
xyte-cli tui --headless --screen dashboard --once --format json --tenant acme

Install, utilities, workflows

Configure once, preprocess utility inputs, then run deterministic flows and reports.

XYTE_CLI_KEY="<your-key>" xyte-cli setup run --non-interactive --tenant acme --connectivity auto
xyte-cli status --tenant acme --mode fast --format json
xyte-cli inspect fleet --tenant acme --format json
xyte-cli inspect deep-dive --tenant acme --window 24 --format json > /tmp/deep-dive.json
xyte-cli report generate --tenant acme --input /tmp/deep-dive.json --out /tmp/xyte-report.pdf

Workflows + utilities

Unified ops command map

For non-technical operators: think of this as one pipeline. You collect signals, shape data with utilities, run deterministic flows, and end with audit-ready artifacts and reports.

Step 1

Collect signals

Start with endpoint reads, watch snapshots, or source files.

call / watch / files
Step 2

Shape inputs

Normalize messy data into execution-ready payloads.

utility prepare
Step 3

Plan execution

Run safe deterministic flows before any mutation.

flow run --plan
Step 4

Review artifacts

Inspect outputs, decisions, and failure classifications.

manifest + outputs
Step 5

Approve writes

Advance one guarded gate at a time with explicit intent.

--apply --allow-write
Step 6

Share outcome

Generate reports and handoffs that teams can trust.

report / ticket update
Toggle: plain-English walkthrough

Utilities turn raw, inconsistent input into clean structures. Flows then run the same step order every time, pausing at human gates for safety. The artifact bundle records exactly what happened so operators and agents can replay, audit, and summarize without guesswork.

1) Start and verify access

First make sure the environment is healthy and your agent/operator setup is correct.

Skills install

Install coding-agent skill bundles once per workspace.

xyte-cli install --skills

Status + upgrade

Fast readiness checks and deterministic global updates with user-scope skill refresh.

xyte-cli status --mode fast --format json
xyte-cli upgrade --check --format json
xyte-cli upgrade --yes --format json

2) Read and shape data

Pull trusted source data and use utilities to normalize files before any write operation.

Endpoint calls

Discover endpoints and emit structured envelope outputs.

xyte-cli list-endpoints
xyte-cli describe-endpoint organization.devices.getDevices
xyte-cli call organization.devices.getDevices --tenant acme --output-mode envelope --strict-json

Utility pipelines

Preprocess data externally; execute intentionally via CLI.

xyte-cli utility list-actions --format text
xyte-cli utility prepare --action organization.devices.claimDevice --input ./raw.xlsx --output-dir ./tmp

Space import

Dry-run first, then apply with explicit approval.

xyte-cli space import-tree --tenant acme --input ./tmp/space-import-tree.csv
xyte-cli space import-tree --tenant acme --input ./tmp/space-import-tree.csv --apply

3) Run deterministic operations

Use built-in flows for repeatable incident/remediation loops, then customize aliases for your team.

Flow runner

Run deterministic, resumable multi-step ops with explicit human gates and artifact bundles.

xyte-cli flow list
xyte-cli flow run flow.watch-to-triage --tenant acme --plan
xyte-cli flow run flow.guided-remediation --tenant acme --apply --allow-write --resume <run-id>
Toggle: how it behaves

Default mode is safe planning. Apply mode advances one explicit human gate at a time and records every decision.

Custom flows

Create shareable aliases with pinned defaults for agent workflows.

xyte-cli flow create flow.noc-remediate --based-on flow.guided-remediation --var device_id=...
xyte-cli flow edit flow.noc-remediate --var ticket_id=...
xyte-cli flow share flow.noc-remediate --out ./tmp/flow.noc-remediate.json
xyte-cli flow import --file ./tmp/flow.noc-remediate.json
Toggle: when to use this

Use custom flows to pin default context per team, share the alias as JSON, and import it into another workspace.

Flow artifacts + resume

Every run persists machine-readable artifacts for replay, audit, and agent summarization.

  inputs.json

Safety model

Guardrails and contracts

Guarded writes

Mutations require --allow-write. Destructive calls also require --confirm <endpoint-key>.

explicit mutation intent destructive confirmation token

Headless is read-only

tui --headless emits snapshots only; interactive write actions are disabled in headless mode.

JSON frames automation-safe

Stable schema IDs

Validate outputs against versioned contracts before automation rollout.
