Automation

CI and agents.

Use this when Xyte checks or reports need to run without a person typing every command: scheduled jobs, pipeline checks, or shell-capable agents such as Codex, Claude Code, and Copilot Agent mode.

Use whenYou need repeatable setup, inspection, or reports.
InputsThe job goal, tenant context, and a secret source outside the repository.
OutputJSON files, report artifacts, and approval-gated flow summaries.

Workflow

  1. GoalChoose jobDecide whether the run checks, reports, or plans a change.
  2. RuntimeCheck CLIUse the installed command or the recommended package path.
  3. TenantResolve accessSelect a ready tenant or connect one from a secret source.
  4. RunWrite artifactsProduce JSON, reports, or a plan-only flow summary.
  5. GateStop safelyWait for approval before any apply step.

Goal

Automation should be explicit about where the API key comes from, which tenant is used, and whether the command is read-only or write-capable. Use JSON output for machines and plan mode before writes.

CI commands

  1. Check the environment

    Use npx when you do not want to depend on a preinstalled global binary.

    npx -y @xyteai/cli@latest doctor environment --format json

  2. Set up from a CI secret

    Map your CI secret to XYTE_CLI_KEY, then pass it through stdin. This keeps the key out of command history and source files.

    printf "%s" "$XYTE_CLI_KEY" | npx -y @xyteai/cli@latest setup run \
  --non-interactive \
  --tenant <tenant-id> \
  --key-stdin \
  --format json

  3. Run a read-only job

    Strict JSON is the safest output when another tool needs to parse the result.

    npx -y @xyteai/cli@latest ops inspect fleet \
  --tenant <tenant-id> \
  --render json \
  --strict-json \
  --out ./artifacts/xyte-fleet.ci.json

You are done when the job produces a JSON artifact or the agent can point to the command it ran, the tenant it used, and the next safe action.

If it fails

The command is missing

Use the npx command or the workspace-local command recommended by doctor environment.

The secret is empty

Check the CI variable name and whether the job is allowed to read it for this branch or environment.

A parser fails on output

Use the command's JSON output option with --strict-json. Do not parse human-readable terminal text.

The agent wants to apply a change immediately

Stop it and ask for the plan output first. Apply only after the target ids and next action are clear.
